# Celeste Choir FX – efecto VST3 para FL Studio (Windows)

Efecto de audio que convierte una voz en un coro / multitud. Se pone en un canal del mixer, antes o despues de Autotune u otros plugins.

## Controles
- **Armonia**: Unisono (multitud), Mayor, Menor, Quintas y octavas.
- **Voces** (2 a 8), **Desafine**, **Retardo** (separacion en el tiempo), **Humanizar** (variacion lenta de cada voz).
- **Tono** (suaviza agudos), **Abrir** (ancho estereo), **Mezcla** (voz original vs coro).
- **Sala / Reverb** y **Volumen**.

## En FL Studio
1. Copia `Celeste Choir FX.vst3` a `C:\Program Files\Common Files\VST3`.
2. Options -> Manage plugins -> Find installed plugins.
3. En el mixer, pon el plugin en un slot de efectos del canal de tu voz.
